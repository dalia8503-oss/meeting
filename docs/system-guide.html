    ③ 사용하는 흐름

    화면에서는 아래 순서로 진행합니다. AI의 추천은 사람이 확인해야만 확정됩니다.

    ④ 실행 방법

    내 PC에서 돌려 보는 방법입니다. 명령은 (PowerShell)에 붙여 넣습니다.

    0. 준비물: Python, Node.js, 그리고 Gemini 키(로 저장).

    1. 비밀 키 설정 — 프로젝트 폴더의 .env 파일에 한 줄로 적습니다.

    GEMINI_API_KEY=여기에_키만_붙여넣기
    ⚠ 키 값에는 키 문자열만 넣습니다. .env 내용을 통째로(두 줄) 붙여 넣으면 요청이 깨집니다. 키가 화면·로그·채팅에 보였다면 폐기하고 새로 발급하세요.

    2. 백엔드* 실행 () — 데이터를 처리하는 서버

    pip install -r requirements.txt
$env:PYTHONPATH="src"
$env:MAA_MODE="demo"     # demo: 외부 AI 호출 없음 / live: 실제 Gemini 사용
uvicorn meeting_action_agent.api.app:create_app_from_env --factory --port 8000

    3. 프런트엔드* 실행 () — 눈에 보이는 화면

    cd frontend
npm install
npm run dev

    브라우저에서 http://localhost:5173을 엽니다. 오른쪽 위에 DEMO 또는 LIVE 배지가 보이면 서버와 연결된 것입니다.

    💡 다른 PC에서 접속하려면 서버를 --host 0.0.0.0으로 열고, 허용할 주소를 MAA_CORS_ORIGINS()에 적습니다. 같은 네트워크에서만 쓰세요.

    구현보다 테스트를 먼저 만든 프로젝트입니다. 지금은 외부 AI를 부르지 않는 자동 테스트가 1005개 있고 모두 통과합니다.

    python -m pytest -q                    # 백엔드 자동 테스트
cd frontend
npm run build                          # 화면 코드 오류 검사 + 빌드
npm run lint                           # 코드 스타일 검사
    화면(UI)의 버튼 동작은 아직 자동 테스트가 없어서, 직접 눌러 확인해야 합니다.

    는 화면과 서버를 따로 올립니다. 서버는 파일 저장과 긴 처리가 필요해서 상시 실행 서버가 맞습니다.

    1. GitHub에 코드 올리기 (git push)
    2. 백엔드 → Render: 저장소 연결 → render.yaml 자동 적용 → 환경 변수 GEMINI_API_KEY 입력
    3. 프런트 → Vercel: 저장소 연결 → Root Directory frontend → 환경 변수 VITE_API_BASE에 서버 주소 입력
    4. 둘을 연결: Render의 MAA_CORS_ORIGINS에 Vercel 주소 입력 후 재배포
    무료 플랜은 서버가 재시작되면 저장된 회의가 사라지고, 15분 쉬면 잠들어 첫 접속이 느립니다. 인증이 없으므로 가상 데이터로만 시연하세요.
